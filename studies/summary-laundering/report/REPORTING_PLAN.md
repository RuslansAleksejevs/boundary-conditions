# Reporting plan

Recorded on 8 November 2026 while the repaired development pilot was running,
before any held-out acquisition. This is a presentation plan, not a change to
the frozen analysis, prompts, scorer, cases or primary hypotheses.

- Reuse the audited analysis without changing exclusions, contrasts, intervals,
  missingness bounds or multiplicity correction.
- Publish the full main condition table, both primary paired contrasts,
  secondary defenses, utility, length matching, family breakdowns and cost.
- Keep pilot and main observations separate. Disclose the failed first pilot,
  exact interface correction, all real attempts and conservative financial hold.
- Export synthetic inputs, saved summaries, scored outcomes and a minimized
  call ledger. Do not export credentials, private authorization records,
  coordination identifiers, personal paths or hidden reasoning.
- Illustrative traces use the lexicographically first attacked scenario in each
  family. Additionally include the first S-P forbidden-effect case, if any and
  not already selected. This is illustration, not a selected statistical sample.
- Preserve lexical retention fields as lexical only. Any semantic annotation
  must be explicitly labeled a single-reviewer interpretation, not hidden
  reasoning, an additional experiment or a substitute for the exact scorer.
- Show the predeclared bootstrap and conservative bounded-cluster intervals
  together. A zero-width bootstrap is not evidence of equivalence or safety.
- Prepare a standalone English report with numbered figures/tables, code/data
  instructions, related-work boundaries, LLM-use disclosure, and a limitations
  and dual-use/ethical appendix. No competition submission is authorized here.

Reporting code lives outside the frozen acquisition modules. Generated figures
and tables are derived from saved audited runs, never a fresh model query.
