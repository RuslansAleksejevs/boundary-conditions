## Check the evidence offline

From the repository root:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 studies/summary-laundering/report/reader/evidence.py --check
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s studies/summary-laundering/report/reader -p 'test_*.py' -v
```

The helper repeats the existing public main and pilot checks, checks the frozen
scientific inventory, derives the tables and example records, and compares all
generated bytes. The source map binds 18 original JSON files. Correct-completion
table denominators stay scheduled; effect denominators stay observed, with
missing outcomes explicit. Neither pilot observations nor invalid responses are
silently replaced or pooled into a better result.

Nine reporting tests check counts, denominators, source pointers, exact examples,
format rejection, typography, generated artifacts and accounting distinctions.
The existing 166 harness tests remain separate. No check makes a model request
or authenticates the provider's private history. Read-only checking uses Python's
standard library; no package installation is needed.

## Build and check the PDF

From this directory, with the existing cached Tectonic 0.16.9 toolchain:

```sh
tectonic --only-cached --untrusted who-said-that.tex
PYTHONDONTWRITEBYTECODE=1 python3 check_pdf.py
```

The optional PDF check uses the existing `pdfinfo` and `pdftotext` commands. It
checks the total page limit, 150–250-word abstract, first-page clickable repository
URL, required disclosures, private/out-of-scope wording and the exact three
quoted passages after Unicode/whitespace normalization. Visual review is still
needed. Actual release checks are recorded in [CHECKS.md](CHECKS.md).

`evidence.py --render` is a reporting-only developer command: it refreshes only
`evidence.tex`, `format-example.tex` and `source-map.json` in this directory.
Ordinary readers should use `--check`. The helper never writes scientific inputs,
historical PDFs or old analysis. Changes to an observation are not a way to fix
a failed reader-report check.
