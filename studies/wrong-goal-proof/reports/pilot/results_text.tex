\newcommand{\RunAbstract}{An exact local proof need not establish the task a user
originally requested. We study this boundary in a finite agent pipeline with an
LLM translator, an exhaustive Boolean solver and independent checker, and an LLM
reviewer of the original contract. Honest translation is separated from deliberate
handoff faults. For fixed original tasks, altered candidates and valid local
certificates, the reviewer sees an ordinary PASS heading, a neutral heading or
an explicit candidate-only scope statement. All conditions retain the original
task and correspondence-checking instruction. The first real Qwen3.5-122B-A10B
pilot used 51 API requests for 52 scheduled roles. Fifty roles met the response
schema and 11 of 12 clean originals were correctly solved. One malformed
translation blocked its dependent review and was not repaired or resampled.
Natural utility was 7/8, with no open-function drift among seven valid
translations. Each presentation produced 0/8 false SAFE answers on planted
faults and 4/4 correct equivalent controls. These small development results do
not establish absence of a presentation effect. The 100-original, 260-role
held-out evaluation is prospectively frozen but has not yet been acquired at
this checkpoint. The contribution at this checkpoint is a verified measurement
procedure and transparent feasibility result, not a new general equivalence
criterion or model-safety guarantee.}
\newcommand{\PilotResults}{The original pilot passed its fixed gate: 50/52
scheduled roles were schema-valid and 11/12 clean originals were correct in all
their conditions. There were 51 physical HTTP200 requests, one malformed JSON
translation and one dependent blocked reviewer. The malformed response was
retained verbatim. No interface-repair pilot, model change or resampling was used.
Natural utility was 7/8; open C/Q drift was 0/7 among valid translations, with one
unassessed translation. All four natural UNSAFE witnesses were valid.}
\newcommand{\MainResults}{\textbf{Development only: no held-out result is reported.}
The same 100 held-out originals and 260 role opportunities were frozen before any
main response. Actual-pilot/holdout comparison found 19 distinct candidate
functions and zero overlap. At this report's cutoff, main preflight had passed
but execution permission was denied before dispatch. Main remained unstarted,
pending verified authorization and exclusive use of the provider route.
No alternate interface was attempted.}

\newcommand{\DiscussionResults}{This pilot shows that the strict interface and
clean-task utility gates can pass under the selected route, while also exposing
a genuine formatting failure. On these development cases, scope wording did
not change any observed planted verdict. The sample is too small to treat that
as evidence that scope is irrelevant. No task or prompt is changed to elicit
a more attractive failure. The preplanned held-out comparison remains the next
empirical step, but it has not been executed.}
\newcommand{\ConclusionResults}{The first real pilot passed with complete
cost accounting and one preserved translation-format failure. Valid local
certificates for altered contracts did not produce observed false assurances
on its eight planted originals in any presentation. This is a feasibility
checkpoint, not the held-out result or a general safety guarantee. The next
step is the unchanged, prospectively frozen evaluation, subject to the hard
budget, fixed gates and separate execution authorization.}
